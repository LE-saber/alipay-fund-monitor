# 支付宝基金监控

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md)

**基于 [AutoX.js](https://github.com/aiselp/AutoX) 的 Android 基金持仓监控与策略自动化。**

> **具备真实资金操作能力：**真实模式会在支付宝买卖基金并产生真实扣款。专用的 1 元测试也是真实买入。先使用默认 dry-run 模拟模式，检查计划后再决定是否启用真实操作。

本项目供个人使用，通过 Android 无障碍服务读取持仓、显示基金卡片并运行配置好的策略，不构成投资建议。自动化可能与平台条款冲突，也可能因界面变化失效；MIT 许可不对资金损失提供担保。

## 功能

- 从支付宝基金持有页采集名称、持仓金额、昨日／持有收益和收益率，并与页面总额对平。
- 手机端搜索／排序、红涨绿跌卡片及采集／策略进度悬浮窗。
- 独立运行批次（保留最近 100 次）、订单明细、当前操作完成后暂停，以及从持久化进度续跑。
- 买卖流程包含金额护栏、大额确认、本地审计；支付密码使用 Android Keystore 支持的 AES-GCM 加密保存。
- 四种可配置策略模板，执行顺序为先卖后买。

### 策略语义

| 模板 | 计划行为 |
| --- | --- |
| `base` 底仓 | 持仓金额低于目标时，按配置金额提出买入 |
| `dca` 定投 | 对启用组别内每只基金提出买入，多个组命中时取最高组金额 |
| `costReduce` 降本 | 亏损时取首个匹配且启用的亏损档，或已启用的兜底档 |
| `takeProfit` 止盈 | 取最高匹配且启用的收益档，按配置份额比例卖出 |

买入侧的 `base` 与 `dca` 取较高金额，相同金额时 `base` 优先。命中的 `costReduce` 金额会与胜出项**相加**，合并为该基金的一笔买单；不能把全部策略概括为“一律取最高金额”。

## 执行护栏与限制

- `dryRun` 默认 `true`，模拟流程在提交支付密码前停止；真实模式要求已配置支付密码。
- 护栏检查金额类型、小数精度、上下限及二次确认阈值。
- 单只基金异常独立处理，记录失败与页面恢复情况。
- 批次状态持久化记录已完成与不确定操作；中断时正在提交的一笔会标为待核对，续跑时跳过，避免盲目重复买入。
- 专用真实测试把请求金额固定为 1 元，但资格、平台拒绝与最终结果仍取决于支付宝，它不是无风险沙箱。
- 审计日志：`/sdcard/Download/alipay_trade.log`。日志、持仓及支付设置属于私有数据。

## Android 运行

需要 **AutoX.js v6**、无障碍服务和悬浮窗权限。原项目记录采用红米 HyperOS / Android 15 环境，不代表所有设备兼容。

1. 在自己的手机安装 AutoX.js v6，并授予所需权限。
2. 使用 Auto.js–Autox.js VSCode 扩展通过 Wi-Fi 连接手机，打开 `main.js` 后按 F5。
3. **↻** 采集，**⚙** 检查配置和策略，**▶** 打开策略运行流程。
4. 验证导航、采集和计划时保持 dry-run 开启。

应用界面仍为中文；README 多语言化不会更改程序行为或界面语言。

## 打包

`project.json` 将 `main.js` 设为入口，`res/logo.png` 设为图标。原流程使用本地准备的 `release/`，该目录被 Git 忽略，不随当前检出提供。请在本地准备项目文件和资源、复制到手机，再通过 AutoX.js 打包菜单选择“界面应用”；生成 APK 后使用 `adb install` 安装。改动设备操作前，阅读 [原导航和支付流程记录](verified-flows/README.md)。

## 开发与源码导航

| 路径 | 用途 |
| --- | --- |
| `main.js` | 自包含 Android 界面、采集、交易和策略流程 |
| `src/` | 提取出的逻辑、配置与诊断；对应逻辑也内联于 `main.js` |
| `test/` | Node 纯逻辑测试 |
| `verified-flows/` | 已记录的导航／支付脚本及说明 |
| `monitor/` | ADB 采集及 HTML 监控面板 |
| `probe*.js`、`test_pwd_flow.js` | 设备诊断；部分会到达支付页面，运行前先检查 |

可用的纯逻辑检查：

```bash
node test/strategy-logic.test.js
node test/trade-logic.test.js
node test/apply-query-sort.test.js
node test/run-history.test.js
```

这些测试不能验证当前支付宝界面或真实成交。文档维护不会运行支付流程。
