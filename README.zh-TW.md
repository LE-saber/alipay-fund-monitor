# 支付寶基金監控

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md)

**使用 [AutoX.js](https://github.com/aiselp/AutoX) 的 Android 基金持倉監控與策略自動化。**

> **具備真實資金操作能力：**真實模式會在支付寶買賣基金並產生實際扣款。專用的人民幣 1 元測試也是真實買入。請先使用預設 dry-run 模擬模式，檢查計畫後再決定是否啟用真實操作。

本專案供個人使用，透過 Android 無障礙服務讀取持倉、顯示基金卡片並執行設定好的策略，不構成投資建議。自動化可能與平台條款衝突，也可能因介面變更失效；MIT 授權不對資金損失提供保證。

## 功能

- 從支付寶基金持有頁擷取名稱、持倉金額、昨日／持有收益與報酬率，並與頁面總額核對。
- 手機端搜尋／排序、紅漲綠跌卡片，以及擷取／策略進度浮動視窗。
- 獨立執行批次（保留最近 100 次）、訂單明細、目前操作完成後暫停，以及從持久化進度繼續執行。
- 買賣流程包含本機稽核，支付密碼以 Android Keystore 支援的 AES-GCM 加密保存；買入流程另有金額檢查與大額確認。
- 四種可設定的策略範本，執行順序為先賣後買。

### 策略語義

| 範本 | 計畫行為 |
| --- | --- |
| `base` 底倉 | 持倉金額低於目標時，按設定金額提出買入 |
| `dca` 定期定額 | 對已啟用群組內每隻基金提出買入，多群組命中時取最高群組金額 |
| `costReduce` 降低成本 | 虧損時取首個符合且啟用的虧損級距，或已啟用的備援級距 |
| `takeProfit` 停利 | 取最高符合且啟用的收益級距，按設定單位比例賣出 |

買入側的 `base` 與 `dca` 取較高金額，同額時 `base` 優先。符合條件的 `costReduce` 金額會與勝出項**相加**，合成該基金的一筆買單；不能將全部策略概括為「一律取最高金額」。

## 執行檢查與限制

- `dryRun` 預設為 `true`，模擬流程在提交支付密碼前停止；真實模式要求已設定支付密碼。
- 買入側檢查金額型別、小數精度、上下限及再次確認門檻。賣出依單位數或比例執行，不套用這些買入金額限制或大額確認門檻。
- 單隻基金異常獨立處理，記錄失敗與頁面恢復情形。
- 批次狀態持久保存已完成與不確定操作；中斷時正在提交的操作會標示待核對，恢復時略過，以避免盲目重複買入。
- 專用真實測試將請求金額固定為人民幣 1 元，但資格、平台拒絕與最終結果仍取決於支付寶；它不是零風險沙箱。
- 稽核日誌：`/sdcard/Download/alipay_trade.log`。日誌、持倉及支付設定屬於私人資料。

## 在 Android 執行

需要 **AutoX.js v6**、無障礙服務及浮動視窗權限。原專案記錄使用紅米 HyperOS / Android 15 環境，不代表所有裝置皆相容。

1. 在自己的手機安裝 AutoX.js v6，並授予所需權限。
2. 使用 Auto.js–Autox.js VSCode 擴充套件經 Wi-Fi 連線，開啟 `main.js` 後按 F5。
3. **↻** 擷取，**⚙** 檢查設定與策略，**▶** 開啟策略執行流程。
4. 驗證導覽、擷取與計畫時，保持 dry-run 啟用。

應用程式介面仍為中文；README 多語言化不會改變程式行為或介面語言。

## 封裝

`project.json` 將 `main.js` 設為入口，`res/logo.png` 設為圖示。原流程使用本機準備的 `release/`，該目錄被 Git 忽略，不隨目前工作副本提供。請在本機準備專案檔案及資源、複製到手機，再於 AutoX.js 封裝選單選擇「介面應用程式」；產生 APK 後以 `adb install` 安裝。更改裝置操作前，請先閱讀[原導覽與支付流程記錄](verified-flows/README.md)。

## 開發與原始碼導覽

| 路徑 | 用途 |
| --- | --- |
| `main.js` | 自包含 Android 介面、擷取、交易與策略流程 |
| `src/` | 擷取出的邏輯、設定與診斷；對應邏輯也內嵌於 `main.js` |
| `test/` | Node 純邏輯測試 |
| `verified-flows/` | 已記錄的導覽／支付指令碼及說明 |
| `monitor/` | ADB 擷取與 HTML 監控面板 |
| `probe*.js`、`test_pwd_flow.js` | 裝置診斷；部分會到達支付頁面，執行前先檢查 |

可用的純邏輯檢查：

```bash
node test/strategy-logic.test.js
node test/trade-logic.test.js
node test/apply-query-sort.test.js
node test/run-history.test.js
```

這些測試無法驗證目前支付寶介面或真實成交。文件維護不會執行支付流程。
